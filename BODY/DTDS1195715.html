Description of diagram

This document introduces the meaning of component color and corresponding symbols in technical illustration.

Color description

For easy understanding, the illustrations in this manual have the following 5 colors, each of which represents its corresponding meaning.

1 - Purple: It indicates fixing or fastening components, such as connectors, pipeline joints, bolts, nuts, screws, clips and clamps.

For example, the figure below shows fasteners.

2 - Blue: It indicates the main body components that need to be removed or installed.

For example, the figure below shows that the component to be removed is the front-end module positioning and mounting plate.

3 - Yellow: It indicates the components that need to be moved during operation but do not need to be removed from the vehicle body.

For example, the figure below shows that the outer panel of gutter channel is moved to the right side of vehicle body.

4 - Gray: background object, which is not described or introduced, but is one of the elements of the overall environment and status of the figure, as shown in the above figure.

5- White: background of the picture.
